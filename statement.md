# Interactive Campus Map

## Problem Statement
Finding different locations on a large campus can be difficult, especially for new students and visitors. Students may not know where academic buildings, food areas, libraries, hostels, medical facilities and other important places are located. They may also need information about a particular location or want to know the approximate distance between two places. This project provides a simple Python-based interactive campus map that helps users find and understand different campus locations.

## Scope of the Project
The project focuses on displaying and managing information about important locations on the VIT Bhopal campus. The location data is stored in a CSV file and can be updated when required. The program provides a menu through which users can view the campus map, search for locations, calculate distances, find nearby locations, filter locations by category, view location details and display all available locations.

The project mainly focuses on providing useful campus location information through a simple Python program and an interactive map.

## Target Users
The main users of this project are:

* New students
* Existing students
* Faculty members
* Visitors to the campus

## High-Level Features
* Displays important campus locations on an interactive map
* Uses different marker colours for different location categories
* Provides a search option for finding locations
* Calculates the approximate distance between two locations
* Finds nearby locations based on distance
* Filters locations according to their category
* Displays details of a selected location
* Displays all available campus locations
* Stores location information in a CSV file
* Provides a simple menu-based interface
