# Interactive Campus Map

## Problem Statement

Finding different locations on a large campus can be difficult, especially for new students. Students may not know where academic buildings, food areas, libraries, hostels, medical facilities and other important places are located. This project provides a simple interactive map to help users find and understand different campus locations.

## Scope of the Project

The project focuses on displaying important campus locations on an interactive map. Users can view information about different places, search for a particular location and calculate the approximate distance between two selected locations. The location data is stored in a CSV file and can be updated when required.

## Target Users

The main users of this project are:

* New students
* Existing students
* Faculty members
* Visitors to the campus

## High-Level Features

* Displays important campus locations on an interactive map
* Uses different marker colours for different categories
* Shows information about each location
* Provides a search option for finding locations
* Calculates the approximate distance between two locations
* Handles invalid location numbers during distance calculation
